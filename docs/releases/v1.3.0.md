# Apple Music Duplicate Finder v1.3.0

Quality and compatibility release since v1.2.5. The extension remains read-only, keeps only the `activeTab` and `scripting` permissions, processes playlist data locally, and never removes or changes your music.

## What's new

- **More dependable Apple Music connectivity.** Catalog playlists use the visible storefront; a same-ID route change to another storefront is rejected. MusicKit initialization gets a bounded wait, raw and nested response envelopes are supported, and nested `Retry-After` values are honored.
- **More complete scans.** A page that promises a continuation but returns empty is treated as truncated/incomplete, not as a successful end. Wrapper and body totals/continuation evidence must agree; conflicting evidence fails safely.
- **Better failure handling.** Failed, cancelled, or mid-scan-close rescans keep the last completed result, badge and Clear action visible, explicitly labelled as the previous completed scan. Only a fully completed, validated scan replaces the last success.
- **Safer cache lifecycle.** Cache freshness compares every shared marker plus a known total, so a same-date revision change is stale. Corrupt, oversized or internally inconsistent cache entries are rejected.
- **Better Copy/CSV reliability.** Copy and CSV keep the cached playlist name when the player is unavailable. CSV formula injection behind leading whitespace, controls, invisible characters, BOM, fullwidth forms or U+2212 is neutralized.
- **Accessibility and presentation.** Compact result cards, wrapped result counts, bounded keyboard-focusable position expansion with ARIA state, automatic text direction, omitted empty artists, higher-contrast placeholders and controls, forced-colors boundaries and outlined result actions.
- **Stronger privacy and security boundaries.** Cross-context replies and track entries must be plain records; malformed requests/errors are rejected; unexpected-error logging is sanitized. Raw response body consumption remains inside cancellation, timeout and route-change guards.
- **Release-quality tooling.** A dependency-free accessibility audit, fixture network-origin allowlist, render/restore timing, deterministic clean-rebuild packaging checks and a benchmark covering reader, matching, CSV, filter/sort, retained heap and cancellation.

## Compatibility

- Your existing theme choice and last completed cached scan are preserved after updating from v1.2.5. The `amdf:theme:v1` and `amdf:last-scan:v1` storage keys and the version 1 cache schema are unchanged; valid v1.2.5 caches load without migration.
- Malformed or inconsistent cached data is discarded rather than rendered as current results.
- Published v1.2.5 tags, release assets and download links remain unchanged.

## Validation

`npm run check` passed on Windows with Node 26.12.1 after the release changes: **161 unit tests**, **71 browser fixture scenarios**, the installed-extension smoke suite, deterministic ZIP/checksum/tamper checks and static security checks. `npm run audit` reported zero vulnerabilities. Two independent source reviews found and verified fixes for conflicting pagination envelopes and raw-response guard escapes; their final regression tests pass.

These checks use controlled fixtures. Live Apple Music, branded Chrome/Edge toolbars, screen-reader speech and additional account/region combinations were not independently tested for this release; the manifest declares Chrome and Edge 111 or newer as the manual compatibility floor.

## Installation

Requires Chrome or Edge **111** or newer on desktop.

1. Download `apple-music-duplicate-finder-v1.3.0.zip` and extract it into a folder you intend to keep.
2. Open `chrome://extensions` (or `edge://extensions`) and enable **Developer mode**.
3. Choose **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Pin the extension, sign in at music.apple.com, open a playlist, and scan.

Verify the download with `apple-music-duplicate-finder-v1.3.0.zip.sha256`; see [download verification](https://github.com/awishtodiexz/Apple-Music-duplicate-finder/blob/v1.3.0/docs/RELEASING.md#verify-a-download). Unpacked extensions do not update automatically.

## Known limitations

- The popup closes, and an in-progress scan is discarded, when it loses focus; use **Open in a window** first. Completed scans are cached.
- Same-count playlist edits and reordering may escape detection when Apple supplies no usable marker.
- Scans stop at the ten-minute, 50,000-entry, 2,000-page or 16-million-metadata-character limits; failed scans return no partial results. At 100 entries per page, 50,000 tracks still means 500 sequential requests.
- Duplicate groups are rendered 50 at a time; there is no virtualization for very large result sets.
- Entries without reliable identifiers are excluded, and different catalog editions remain separate.
- Apple can change its web player or MusicKit interface at any time.
- The toolbar badge is extension-global, not per-tab.

# Apple Music Duplicate Finder v1.1.1

This is a post-release reliability and security patch. It keeps the read-only toolbar popup and exact identifier-based duplicate matching. Playlist data is still processed locally, and the extension never removes or changes your music.

## Fixes and improvements

- **Catalog storefront correctness.** Catalog playlist scans now prefer the storefront from the visible playlist URL and use the player's storefront only when the route omits one. This avoids reading a different regional playlist when the two values differ.
- **Correct singular batch label.** When exactly one duplicate song remains to display, the button now reads **“Show 1 more song”** instead of **“Show 1 more songs.”**
- **Stricter extension-page CSP.** Added `default-src 'self'` so unspecified resource types cannot load from arbitrary origins.
- **Regression coverage.** Added storefront-precedence and singular remaining-batch tests. The suite now contains **66 unit tests** and **48 UI fixture scenarios**.
- **Dependency maintenance policy.** Dependabot now defers TypeScript and `@types/node` major updates for an explicit compatibility review.
- **Documentation.** Refreshed the README screenshot; added installation requirements, a feature summary, troubleshooting guidance, checksum verification, and clearer privacy/network wording.
- **Repository hardening.** Enabled private vulnerability reporting, secret scanning with push protection, Dependabot alerts and security updates, CodeQL default setup, and required CI checks on `main`.

## Installation

Requires Chrome or Edge **111** or newer on desktop.

1. Download `apple-music-duplicate-finder-v1.1.1.zip` and extract it into a folder you intend to keep.
2. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
3. Enable **Developer mode**, then choose **Load unpacked**.
4. Select the extracted folder containing `manifest.json`.
5. Pin the extension, sign in at `music.apple.com`, open a playlist, and scan.

The matching `apple-music-duplicate-finder-v1.1.1.zip.sha256` file verifies download integrity. See [download verification](https://github.com/awishtodiexz/Apple-Music-duplicate-finder/blob/v1.1.1/docs/RELEASING.md#verify-a-download). Unpacked extensions do not update automatically.

## Known limitations

- The toolbar popup closes when focus is lost, including clicking outside it. Keep it focused while scanning; closing it discards the scan.
- Apple Music does not guarantee atomic playlist snapshots. Same-count edits and reordering may escape detection even with available metadata checks.
- Very large or slow scans may stop at the five-minute, 50,000-entry, 2,000-page, or 16-million-metadata-character limits. Failed or limited scans accept no partial results.
- Different catalog editions remain separate, and entries without reliable identifiers are excluded from matching.
- Aborting an underlying request depends on the player API honoring the supplied signal. A late result cannot update a cancelled or later scan.
- Apple can change its web player and MusicKit interface; live compatibility may change.

The permissions remain `activeTab` and `scripting`. There are no broad host permissions, analytics, telemetry, or third-party playlist uploads. No side panel or marketplace publication is included.
